# Support

FluxForge-NAMC is an experimental open-source research project maintained on a
best-effort basis. There is no commercial support commitment or guaranteed
response time.

## Where to ask

- Use a bug report for reproducible defects.
- Use a feature request for a scoped capability proposal.
- Use a research proposal for experiments, algorithms, datasets, or model
  changes that need technical discussion.
- Use GitHub Discussions for general questions if Discussions are enabled.
- Follow `SECURITY.md` for vulnerabilities; never report them publicly.

Before opening a request, search existing issues and read the current roadmap.
Include enough context and evidence for another contributor to reproduce or
evaluate the request.

## Current limits

The project currently provides no support for physical inverter wiring,
high-voltage commissioning, road-vehicle deployment, or bypassing hardware
protections. Questions that require unsafe experimentation or imply production
readiness may be declined.
