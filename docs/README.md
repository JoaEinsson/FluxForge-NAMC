The implementation phases will add dedicated documents for architecture,
mathematical conventions, magnetic modeling, identification, control,
modulation, optimization, simulation, portability, and detailed safety design.
Documentation must describe implemented behavior honestly; planned behavior
must remain clearly labeled as planned.
